# CineSynopsis - 产品需求文档

## Overview
- **Summary**: CineSynopsis 是一款基于多模态人工智能的视频自动剪辑工具，专为影视内容二次创作、快速预览和知识传播设计。用户提供完整电影视频文件并指定期望输出时长，系统自动分析剧情结构、识别关键情节点，生成浓缩剪辑视频，并替换为AI生成的讲述式旁白。
- **Purpose**: 解决影视内容二次创作效率低下的痛点，让用户能够快速将长视频转化为精华摘要，节省大量手动剪辑时间。
- **Target Users**: 影视解说创作者、电影爱好者、教育与研究机构、内容平台运营人员

## Goals
- 实现视频自动场景分割与关键情节识别
- 支持多种视频格式输入与自定义输出时长
- 生成自然流畅的AI旁白并实现音画同步
- 提供完整的项目文件保存与导出功能
- 支持批量处理多部影片

## Non-Goals (Out of Scope)
- 不提供视频上传到云端存储的功能
- 不包含社交分享功能
- 不提供完整的视频编辑功能（如复杂特效、调色等）
- 不支持实时视频流处理

## Background & Context
- 影视内容二次创作需求旺盛，但手动剪辑耗时费力
- 多模态AI技术（计算机视觉、语音合成、自然语言处理）已成熟
- 用户需要简单易用的工具，一键生成高质量视频摘要

## Functional Requirements
- **FR-1**: 支持 MP4、MOV、MKV、AVI 等常见视频格式输入
- **FR-2**: 用户可指定目标输出时长（3/5/10分钟等）
- **FR-3**: 提供保留原字幕或内嵌新字幕选项
- **FR-4**: 自动进行场景分割与筛选（基于视觉和音频分析）
- **FR-5**: 对每个场景进行叙事权重打分，识别关键事件、高潮、结局等
- **FR-6**: 追踪人物关系与因果链，确保故事完整性
- **FR-7**: 使用动态规划优化剪辑序列，匹配目标时长
- **FR-8**: 场景间自动添加平滑转场效果
- **FR-9**: 生成连贯的剧情叙述文本
- **FR-10**: 支持多语言、多音色的TTS语音合成
- **FR-11**: 实现旁白与画面的节奏同步
- **FR-12**: 提供无版权背景音乐选项
- **FR-13**: 支持 MP4 (H.264/H.265) 格式导出，可调节分辨率与码率
- **FR-14**: 支持项目文件保存与后续微调
- **FR-15**: 支持批量处理多部影片

## Non-Functional Requirements
- **NFR-1**: 视频处理速度：1小时电影生成3分钟摘要时间 < 10分钟
- **NFR-2**: 输出视频质量：旁白自然度评分 > 4.5/5，内容完整性评分 > 4/5
- **NFR-3**: 支持并行处理多个视频任务
- **NFR-4**: 支持取消正在进行的任务
- **NFR-5**: 提供清晰的处理进度反馈
- **NFR-6**: 错误处理：视频文件损坏、格式不支持等情况需友好提示

## Constraints
- **Technical**: 
  - 后端框架：Python FastAPI
  - 视频处理：FFmpeg
  - AI模型：OpenAI/本地LLM + Whisper + TTS引擎
  - 前端：React + TypeScript
- **Business**: 需使用无版权背景音乐素材
- **Dependencies**: 外部AI服务API或本地模型部署

## Assumptions
- 用户拥有合法的视频文件使用权
- 系统具备足够的计算资源进行视频处理和AI推理
- 网络连接可用（如使用云端AI服务）

## Acceptance Criteria

### AC-1: 视频输入与目标设定
- **Given**: 用户选择一个MP4/MOV/MKV/AVI格式的视频文件
- **When**: 用户指定目标输出时长（如3分钟）并选择字幕选项
- **Then**: 系统接受输入并显示处理进度
- **Verification**: `programmatic`

### AC-2: 场景分割与筛选
- **Given**: 输入一部完整电影视频
- **When**: 系统进行场景分析
- **Then**: 输出场景列表，包含每个场景的时长、类型（关键事件/高潮/过渡等）和权重评分
- **Verification**: `programmatic`

### AC-3: 自动剪辑生成
- **Given**: 场景分析完成
- **When**: 系统执行剪辑优化
- **Then**: 生成符合目标时长的剪辑序列，场景间有平滑转场
- **Verification**: `programmatic`

### AC-4: 旁白生成
- **Given**: 剪辑序列确定
- **When**: 系统生成旁白文本并合成语音
- **Then**: 生成连贯的讲述式旁白，语速适配目标时长
- **Verification**: `human-judgment`

### AC-5: 音画同步
- **Given**: 旁白语音和剪辑视频生成完成
- **When**: 系统进行音画合成
- **Then**: 旁白节奏与画面变化对齐，重要情节点旁白语气加重
- **Verification**: `human-judgment`

### AC-6: 输出与导出
- **Given**: 视频处理完成
- **When**: 用户点击导出按钮
- **Then**: 生成指定格式和分辨率的MP4文件，可下载
- **Verification**: `programmatic`

### AC-7: 项目文件保存
- **Given**: 剪辑完成后
- **When**: 用户选择保存项目
- **Then**: 生成包含剪辑序列、旁白脚本等信息的项目文件
- **Verification**: `programmatic`

### AC-8: 批量处理
- **Given**: 用户添加多部影片到队列
- **When**: 用户启动批处理
- **Then**: 系统依次处理每部影片，显示整体进度
- **Verification**: `programmatic`
