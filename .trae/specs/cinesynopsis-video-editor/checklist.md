# CineSynopsis - 验证检查清单

## 一、功能验证

### 1. 视频输入与目标设定
- [ ] 支持 MP4、MOV、MKV、AVI 格式上传
- [ ] 用户可指定目标输出时长（3/5/10分钟等）
- [ ] 提供保留原字幕或内嵌新字幕选项

### 2. 智能剧情解析
- [ ] 场景分割结果正确存储到数据库
- [ ] 每个场景都有评分（0-1）和类型标签
- [ ] 关键场景（高潮/结局）被正确识别
- [ ] 语音识别结果包含时间戳

### 3. 自动剪辑生成
- [ ] 输出时长在目标时长的 ±10% 范围内
- [ ] 关键场景（评分=1.0）全部被选中
- [ ] 场景间有平滑转场效果
- [ ] 输出视频无原音频

### 4. 旁白生成与替换
- [ ] 旁白文本连贯，覆盖主要剧情
- [ ] 生成的语音文件格式正确（MP3/WAV）
- [ ] 语音自然度评分 > 4.5/5
- [ ] 旁白与画面节奏对齐

### 5. 输出控制
- [ ] 支持 MP4 (H.264/H.265) 格式导出
- [ ] 可调节分辨率与码率
- [ ] 项目文件正确保存（JSON格式）
- [ ] 项目文件可正确导入

### 6. 批量处理
- [ ] 批量任务创建成功
- [ ] 批量进度统计正确
- [ ] 任务取消功能正常工作

## 二、性能验证

### 1. 处理速度
- [ ] 1小时电影生成3分钟摘要时间 < 10分钟

### 2. 任务管理
- [ ] 任务状态正确更新（pending→processing→completed）
- [ ] 进度条正确更新

## 三、质量验证

### 1. 内容质量
- [ ] 旁白自然度评分 > 4.5/5
- [ ] 内容完整性评分 > 4/5
- [ ] 语音识别准确率 > 90%

### 2. 用户体验
- [ ] UI 布局美观合理
- [ ] 错误提示清晰易懂
- [ ] 场景预览界面直观易用

## 四、代码质量

### 1. 测试覆盖率
- [ ] 单元测试覆盖率 > 70%
- [ ] 集成测试覆盖主要流程

### 2. 部署验证
- [ ] Docker Compose 开发环境启动正常
- [ ] Docker Compose 生产环境启动正常
- [ ] 后端服务启动成功，访问 `/docs` 返回 API 文档
- [ ] 前端项目构建成功，无错误

## 五、安全验证

### 1. 文件上传安全
- [ ] 仅允许视频格式上传
- [ ] 超过大小限制的文件被拒绝

### 2. 错误处理
- [ ] 视频文件损坏时友好提示
- [ ] 格式不支持时友好提示
